# PrivateFirewall runtime deps are Python standard library only on BOTH
# platforms for the engine itself (ctypes over WFP/iphlpapi + PowerShell on
# Windows; /proc + a pkexec'd ufw helper on Linux). CI installs only
# PyInstaller to freeze the Windows engine into an .exe.
#
# The single optional dependency below is the LINUX SYSTEM TRAY icon
# (pystray needs PIL images). It is import-guarded — the app serves headless
# without it — and is never installed on Windows (the exe uses the ctypes
# Win32 tray). The QuickOpen deb builder maps it to python3-pil; pystray
# itself is vendored by quickopen-runtime.
Pillow  # Linux tray icon only (deb: python3-pil); import-guarded
pystray  # Linux tray (vendored by quickopen-runtime; deb maps to the AppIndicator GIR typelibs)
